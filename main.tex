\subsection{Persiapan Praktikum}
\par Pada praktikum pertemuan ini, studi kasus yang digunakan adalah pengujian fitur \textit{login} pada website \textbf{SauceDemo} (\url{https://www.saucedemo.com/}) menggunakan Selenium WebDriver dan JUnit 5. Proyek pengujian dibuat dalam bentuk proyek Maven berbasis Java dengan versi compiler \textbf{JDK 17}.

\subsection{Soal Praktikum}
\par Soal praktikum pada pertemuan ini berfokus pada pembuatan otomatisasi pengujian antarmuka untuk proses login pada SauceDemo menggunakan Selenium dan JUnit 5. Skenario pengujian yang dikerjakan adalah sebagai berikut.
\begin{enumerate}
  \item Menguji login berhasil menggunakan beberapa \textit{username} valid (lihat Gambar~\ref{fig:saucedemo-login}) dengan password \texttt{secret\_sauce} dan memverifikasi bahwa halaman berpindah ke \texttt{/inventory.\allowbreak html}.
  \item Menguji login gagal menggunakan akun \texttt{locked\_out\_user} (bukan karena password salah) dan memverifikasi bahwa halaman tidak berpindah ke \texttt{/inventory.\allowbreak html}.
\end{enumerate}

\subsection{Implementasi Pengujian}
\subsubsection{Strategi Pengujian}
\par Pengujian diimplementasikan menggunakan \textbf{JUnit 5} dengan memanfaatkan \textbf{@BeforeEach} untuk inisialisasi browser, \textbf{@AfterEach} untuk menutup browser, serta \textbf{@ParameterizedTest} untuk menjalankan skenario login berhasil pada beberapa data akun. Strategi ini membuat kode pengujian lebih ringkas karena satu method test dapat dieksekusi berulang untuk banyak username.

\subsubsection{Kode Pengujian Selenium}
\par Implementasi pengujian dapat dilihat pada Kode~\ref{lst:sauce-test}. Secara ringkas, test melakukan berikut ini: 
\begin{enumerate}
  \item membuka website SauceDemo,
  \item menemukan elemen \textit{username}, \textit{password}, dan tombol login berdasarkan \textit{id},
  \item mengisi kredensial,
  \item menekan tombol login, lalu,
  \item memeriksa URL akhir sebagai \textit{oracle} pengujian.
\end{enumerate}

\begin{lstlisting}[language=Java, caption={Kode pengujian Selenium pada SauceDemo (SauceTest.java)}, label={lst:sauce-test}]
import org.junit.jupiter.api.AfterEach;
import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertNotEquals;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.params.ParameterizedTest;
import org.junit.jupiter.params.provider.ValueSource;
import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.chrome.ChromeDriver;

public class SauceTest {

  WebDriver driver;
  WebElement username;
  WebElement password;
  WebElement loginButton;

  @BeforeEach
  public void setup() {
    this.driver = new ChromeDriver();
    this.driver.manage().window().maximize();
    this.driver.get("https://www.saucedemo.com/");
    this.username = this.driver.findElement(By.id("user-name"));
    this.password = this.driver.findElement(By.id("password"));
    this.loginButton = this.driver.findElement(By.id("login-button"));
  }

  @ParameterizedTest
  @ValueSource(strings = {
    "standard_user", 
    "problem_user", 
    "performance_glitch_user",
    "error_user",
    "visual_user"
  })
  public void successLoginTest(String usernameValue) {
    this.username = this.driver.findElement(By.id("user-name"));
    this.password = this.driver.findElement(By.id("password"));
    this.loginButton = this.driver.findElement(By.id("login-button"));

    this.username.sendKeys(usernameValue);
    this.password.sendKeys("secret_sauce");
    this.loginButton.click();

    // assert
    String url = this.driver.getCurrentUrl();
    String expected = "https://www.saucedemo.com/inventory.html";
    assertEquals(expected, url);
  }

  @ParameterizedTest
  @ValueSource(strings = {
    "locked_out_user"
  })
  public void failedLoginNotBecauseWrongPassword(String usernameValue) {
    this.username = this.driver.findElement(By.id("user-name"));
    this.password = this.driver.findElement(By.id("password"));
    this.loginButton = this.driver.findElement(By.id("login-button"));

    this.username.sendKeys(usernameValue);
    this.password.sendKeys("secret_sauce");
    this.loginButton.click();

    // assert
    String url = this.driver.getCurrentUrl();
    String expected = "https://www.saucedemo.com/inventory.html";
    assertNotEquals(expected, url);
  }

  @AfterEach
  public void tearDown() {
    this.driver.quit();
  }
}
\end{lstlisting}

\subsubsection{Penjelasan Assertion}
\par Pada method \textbf{successLoginTest} di Kode~\ref{lst:sauce-test}, pengujian memverifikasi keberhasilan login dengan membandingkan URL aktual dengan URL yang diharapkan menggunakan \textbf{assertEquals}. URL yang diharapkan adalah \texttt{https://www.saucedemo.com/inventory.html}. Sementara itu, pada method \textbf{failedLoginNotBecauseWrongPassword}, pengujian memverifikasi kegagalan login dengan memastikan URL aktual \textbf{tidak sama} dengan URL inventory menggunakan \textbf{assertNotEquals}.

\subsection{Hasil Akhir Pengujian}
\par Setelah seluruh skenario dijalankan, hasil pengujian menunjukkan seluruh test pada kelas \textbf{SauceTest} berhasil dieksekusi. Pada proses eksekusi juga muncul peringatan terkait CDP (\textit{Chrome DevTools Protocol}); namun peringatan tersebut tidak menghentikan eksekusi dan test tetap berjalan hingga selesai.

\section{Kesimpulan}
\par Berdasarkan hasil praktikum pertemuan ini, saya memahami bahwa Selenium WebDriver dapat digunakan untuk melakukan otomatisasi pengujian antarmuka web dengan cara mengontrol browser, mencari elemen halaman, dan melakukan aksi seperti mengisi form serta menekan tombol. Dengan bantuan JUnit 5, pengujian dapat disusun secara terstruktur menggunakan anotasi \textbf{@BeforeEach} dan \textbf{@AfterEach} untuk mengelola siklus hidup browser.

\par Selain itu, penggunaan \textbf{@ParameterizedTest} memudahkan pengujian satu skenario yang sama menggunakan beberapa data uji tanpa menulis test berulang. Pada studi kasus SauceDemo, verifikasi dilakukan dengan membandingkan URL hasil login terhadap URL yang diharapkan (\texttt{/inventory.\allowbreak html}) sehingga dapat memastikan proses login berhasil atau gagal sesuai skenario.
